# Richi

Responsive storefront starter for PC components and accessories, built with
plain HTML, CSS, and JavaScript.

## Run locally

Open `richi.html` in a modern browser. No build step or external framework is
required.

## Current features

- Responsive layout, mobile navigation, and dark/light theme toggle.
- Catalog text search, category filtering, and product quick-view placeholders.
- Accessible cart drawer with quantity/removal support for catalog items that
  have verified product IDs, prices, and currency codes.
- Client-side newsletter email validation.

## Before launch

Catalog cards currently contain placeholders. Add verified product information
before enabling add-to-cart or price/popularity sorting. The newsletter form is
not connected to a mailing-list service, and checkout, delivery, returns,
payments, and support information still need store configuration. See
`DEVELOPMENT_PLAN.md` for the follow-up steps.
